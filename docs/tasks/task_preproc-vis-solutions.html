7.1 Данные

Данные являют собой1, выгрузку из учётной системы ювелирной компании. Каждый камень поступает в компанию, проходит геммологическую экспертизу в одной из лабораторий, получает сертификат и выставляется на продажу. Часть камней уже продана, часть ещё ждёт покупателя. Выгрузка сделана 30 июня 2026 года.

Как и любая реальная выгрузка, данные «грязные»: в них есть дубликаты, ошибки ввода, разные форматы дат и непоследовательное написание текстовых значений.

Данные в виде ZIP-архива можно скачать по ссылке.

Ниже приведены ссылки, по которым каждый файл можно прочитать напрямую.

Переменная Описание
id идентификатор камня, DM-00001 и т. д.
carat масса, караты
cut качество огранки: Fair < Good < Very Good < Premium < Ideal
color_clarity переменная, объединяющая две характеристики: цвет — от D (лучший, бесцветный) до J (худший) — и чистоту — I1 (худшая) < SI2 < SI1 < VS2 < VS1 < VVS2 < VVS1 < IF (лучшая); формат записи соответствует названию столбца
depth общая глубина в процентах: z / mean(x, y)
table ширина площадки относительно самой широкой точки, %
price прайсовая (выставочная) цена, долл. США
x, y, z длина, ширина и высота камня, мм
lab код лаборатории, проводившей экспертизу
recv_date дата поступления образца (формат ГГГГ-ММ-ДД)
exam_date дата завершения экспертизы (формат ДД.ММ.ГГГГ)
sale_dttm дата и время продажи (формат ДД/ММ/ГГГГ ЧЧ:ММ); пусто — камень не продан
sale_price фактическая цена продажи, долл. США; пусто — камень не продан
comment заключение геммолога: номер сертификата, флуоресценция, происхождение, замечания о дефектах

7.1.2 diamonds_appraisals.csv — независимые оценки

Для 1500 камней компания заказала оценку у трёх независимых экспертов. Каждая строка соответствует камню, столбцы appraiser_A, appraiser_B и appraiser_C содержат оценочную стоимость в долларах. Если эксперт камень не оценивал, ячейка пустая.
