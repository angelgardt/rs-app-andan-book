8  Задание | Предобработка и визуализация данных

Задания для тренировки навыков предобработки и визуализации данных в tidyverse: импорт, первичное исследование, select() / rename() / filter() / arrange() / mutate(), группировка и агрегация, работа со строками (stringr) и датами (lubridate), объединение таблиц (*_join()), изменение формата (pivot_*()) и ggplot2.

Задания идут по порядку: каждый следующий блок работает с таблицей, полученной в предыдущих. Поэтому сохраняйте промежуточные результаты в объекты, а не просто печатайте их в консоль.

Задания со звёздочкой (★) сложнее остальных.

8.1 Данные

Данные являют собой1, выгрузку из учётной системы ювелирной компании. Каждый камень поступает в компанию, проходит геммологическую экспертизу в одной из лабораторий, получает сертификат и выставляется на продажу. Часть камней уже продана, часть ещё ждёт покупателя. Выгрузка сделана 30 июня 2026 года.

Как и любая реальная выгрузка, данные «грязные»: в них есть дубликаты, ошибки ввода, разные форматы дат и непоследовательное написание текстовых значений.

Данные в виде ZIP-архива можно скачать по ссылке.

Ниже приведены ссылки, по которым каждый файл можно прочитать напрямую.

14.0 Фиксим cut, color и clarity

ВажностьКастомный порядок в строках

Значения переменных cut, color и clarity упорядочены по смыслу (см. кодбук). Однако строкоый тип данных (character) этот порядок не содержат.

  • Изучите справку по функции factor().
  • Измените тип данных у переменных cut, color и clarity с character на ordered factor с соответствующим порядком категорий. Сохраните результат, перезаписав датафрейм.
Скрип изменения типов данных для указанных переменных 
## код необходимо адаптировать под названия объектов, которые вы используете

dm <- dm |> 
  mutate(cut = factor(cut, ordered = TRUE, 
                      levels = c("Fair", "Good", "Very Good", "Premium", "Ideal")),
         color = factor(color, ordered = TRUE, 
                        levels = c("D", "E", "F", "G", "H", "I", "J", "K")),
         clarity = factor(clarity, ordere = TRUE, 
                          levels = c("I1", "SI2", "SI1", "VS2", "VS1", "VVS2", "VVS1", "IF"))
)
