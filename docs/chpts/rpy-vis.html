7  Визуализация данных

Таблица из 9000 строк — это очень много цифр, и охватить их взглядом невозможно. График — это способ превратить таблицу в картинку, по которой закономерности видны сразу. Визуализация нужна на каждом этапе работы с данными: чтобы увидеть, что с данными что-то не так, чтобы понять, какой метод применять, и чтобы показать результат другим. В этой главе мы познакомимся с пакетом ggplot2, который входит в tidyverse и стал стандартом для визуализации в R.

7.1 Зачем нужна визуализация

Прежде чем учиться рисовать графики, разберёмся, почему недостаточно посчитать несколько чисел. Рассмотрим четыре небольших набора данных, каждый из которых содержит по 11 пар значений \(x\) и \(y\). Это знаменитый квартет Анскомба (Anscombe, 1973).

quartet <- read_csv("data/anscombe.csv", show_col_types = FALSE)

quartet |>

            sd_x = sd(x), sd_y = sd(y),
            cor = cor(x, y),

Все четыре набора практически неразличимы по этим числам. Но стоит нарисовать данные:

quartet |>
  ggplot(aes(x, y)) +
  geom_point() +
  geom_smooth(method = "lm", se = FALSE) +
  facet_wrap(~ dataset)

В первом наборе связь действительно приблизительно линейная. Во втором она явно нелинейная, в третьем есть один выброс, который «тянет» линию, а в четвёртом вся связь держится на одном-единственном наблюдении. Числа не могут нам этого сказать, график — может.

Ту же идею доводит до крайности набор Datasaurus (Matejka & Fitzmaurice, 2017): 13 наборов данных с одинаковыми средними, стандартными отклонениями и корреляцией (с точностью до двух знаков), но совершенно разной формой.

datasaurus <- read_csv("data/datasaurus.csv", show_col_types = FALSE)

datasaurus |>
  ggplot(aes(x, y)) +
  geom_point(size = 0.7) +
  facet_wrap(~ dataset, ncol = 4)
Важность

Описательные статистики не заменяют взгляд на данные. Всегда сначала посмотрите на график, и только потом считайте и интерпретируйте числа.

7.2 Графика в базовом R

В R есть встроенные функции для построения графиков, и для быстрой проверки они вполне подходят:

hist(share$time1, breaks = 40, main = "", xlab = "Время первого клика, с")
boxplot(time1 ~ trialtype, data = share, xlab = "Тип пробы", ylab = "Время первого клика, с")

Базовая графика работает по принципу «рисунок на холсте»: каждая функция что-то дорисовывает, и отредактировать уже нарисованное нельзя. Для сложных графиков это неудобно, поэтому дальше мы будем работать с ggplot2.

7.3 Грамматика графики и ggplot2

Пакет ggplot2 построен на идее грамматики графики (grammar of graphics, Wilkinson, 2005; в версии для R — Wickham, 2010). Любой график разбирается на независимые компоненты, которые накладываются друг на друга слоями:

Слои добавляются друг к другу оператором + (не путать с пайпом!). Построим график шаг за шагом, используя данные sharexp. Для начала заведём таблицу со средним временем первого клика для каждого испытуемого. Это сводная таблица: из 9000 строк мы получаем 20.

id_means <- share |>
  summarise(mean_time = mean(time1[correct]),  # время считаем только по верным пробам

7.3.1 Базовый слой

Построение графика начинается с функции ggplot(), в которую передаётся таблица с данными:

id_means |>
  ggplot()

Получился пустой серый прямоугольник — холст. Пока мы не сказали, что на нём рисовать.

7.3.2 Эстетики

Функция aes() связывает переменные таблицы со свойствами графика. Самые важные из них — положение по осям x и y:

id_means |>
  ggplot(aes(x = age, y = mean_time))

Появились оси с подписями и сетка, но самих данных нет: мы не сказали, как их изображать.

7.3.3 Геомы

Способ изображения задаётся геомом. Добавим точки:

id_means |>
  ggplot(aes(x = age, y = mean_time)) +
  geom_point()

Если запустить этот код у себя, R выведет предупреждение о пропущенных значениях (Removed 3 rows containing missing values). Оно не случайно: у троих испытуемых возраст неизвестен, и ggplot2 честно сообщает, что не смог их нарисовать.

К графику можно добавлять сколько угодно слоёв. Например, линию тренда:

id_means |>
  ggplot(aes(x = age, y = mean_time)) +
  geom_point() +
  geom_smooth(method = "lm")

Серая полоса вокруг линии — доверительный интервал для линии тренда; мы научимся его интерпретировать в главе про интервальные оценки.

7.3.4 Другие эстетики

Помимо положения, переменные можно отображать цветом (color, fill), формой (shape), размером (size), прозрачностью (alpha) и другими свойствами:

id_means |>
  ggplot(aes(age, mean_time, color = platform)) +
  geom_point(size = 3)

Обратите внимание: эстетики, которые мы хотим связать с переменной, задаются внутри aes(). Если же мы хотим просто покрасить все точки в один цвет, то задаём параметр вне aes():

id_means |>
  ggplot(aes(age, mean_time)) +
  geom_point(size = 3, color = "steelblue", alpha = 0.7)
Предупреждение

Частая ошибка — написать aes(color = "steelblue"). Тогда ggplot2 решит, что "steelblue" — это название группы (одной на все наблюдения), и раскрасит точки в первый цвет палитры по умолчанию, а в легенде появится надпись steelblue.

7.4 Распределение одной переменной

7.4.1 Гистограмма

Гистограмма (histogram) показывает, как часто встречаются значения из разных диапазонов. Диапазон значений делится на интервалы (bins), и для каждого рисуется столбик, высота которого равна числу наблюдений в интервале.

share |>
  ggplot(aes(time1)) +
  geom_histogram(bins = 50, fill = "lightblue", colour = "white") +
  labs(x = "Время первого клика, с", y = "Число проб")

Вид гистограммы зависит от числа интервалов, поэтому полезно пробовать разные значения bins (или ширину интервала binwidth):

share |> ggplot(aes(time1)) + geom_histogram(bins = 10)
share |> ggplot(aes(time1)) + geom_histogram(bins = 200)

Слишком мало интервалов — и мы теряем детали, слишком много — и картина «рассыпается» на шум.

7.4.2 График плотности

График плотности (density plot) — сглаженная версия гистограммы. Он удобен, когда нужно сравнить распределения в нескольких группах:

share |>
  ggplot(aes(time1, fill = trialtype)) +
  geom_density(alpha = 0.5) +
  labs(x = "Время первого клика, с", y = "Плотность", fill = "Тип пробы")

7.4.3 Ящик с усами

Ящик с усами (boxplot) показывает пять чисел: медиану (линия внутри ящика), первый и третий квартили (границы ящика) и «усы». Точки за пределами усов — потенциальные выбросы. Подробнее о том, как они строятся, мы поговорим в главе про описательные статистики.

share |>
  ggplot(aes(trialtype, time1)) +
  geom_boxplot() +
  labs(x = "Тип пробы", y = "Время первого клика, с")

7.4.4 Скрипичная диаграмма

Скрипичная диаграмма (violin plot) сочетает в себе идеи графика плотности и ящика с усами: форма «скрипки» — это зеркально отражённая плотность.

share |>
  ggplot(aes(trialtype, time1)) +
  geom_violin(fill = "lightblue") +
  geom_boxplot(width = 0.1, outlier.shape = NA) +
  labs(x = "Тип пробы", y = "Время первого клика, с")

Здесь мы добавили на один график два слоя. Параметр outlier.shape = NA убирает точки-выбросы из ящиков, чтобы не рисовать их дважды.

7.4.5 Столбчатая диаграмма

Столбчатая диаграмма (bar plot) показывает числовое значение для каждой категории. В ggplot2 для неё есть два геома, и различие между ними важно:

  • geom_bar() сам подсчитывает, сколько наблюдений приходится на каждое значение переменной (то есть применяет статистическое преобразование count);
  • geom_col() рисует столбики по уже готовым значениям.
id_means |>
  count(platform) |>
  ggplot(aes(platform, n)) +
  geom_col() +
  labs(x = "Платформа", y = "Число испытуемых")
share |>
  ggplot(aes(correct)) +
  geom_bar() +
  labs(x = "Ответ правильный", y = "Число проб")

Столбчатая диаграмма подходит для частот и долей. Для сравнения средних значений она подходит хуже: столбик скрывает разброс данных. В таких случаях лучше использовать графики с интервальными оценками (см. ниже).

Заметка

Гистограмма и столбчатая диаграмма — не одно и то же. Гистограмма строится для непрерывной переменной, интервалы на её оси подбираются автоматически, и столбики стоят вплотную. Столбчатая диаграмма строится для категориальной переменной, столбики разделены промежутками. Подробнее см. главу о случайных величинах.

7.5 Связь двух переменных

7.5.1 Диаграмма рассеяния

Для двух количественных переменных используется диаграмма рассеяния (scatter plot). Мы уже строили её выше (Рисунок 7.6). Покажем, как выглядит связь между временем и точностью на уровне испытуемых:

id_means |>
  ggplot(aes(mean_time, accuracy)) +
  geom_point(size = 2.5) +
  labs(x = "Среднее время первого клика, с", y = "Доля правильных ответов")

7.5.2 Линейный график

Линейный график (line plot) соединяет точки линией и подходит, когда по оси x расположена упорядоченная переменная: время, размер набора, номер пробы. Посмотрим, как зависит среднее время от числа стимулов (setsize) для разных типов проб:

share |>
  filter(correct) |>
  summarise(mean_time = mean(time1), .by = c(trialtype, setsize)) |>
  ggplot(aes(setsize, mean_time, color = trialtype)) +
  geom_line() +
  geom_point() +
  scale_x_continuous(breaks = c(8, 12, 16)) +
  labs(x = "Число стимулов", y = "Среднее время первого клика, с", color = "Тип пробы")

Именно этот график иллюстрирует классическую закономерность зрительного поиска: чем больше стимулов на экране, тем дольше человек ищет цель. Здесь мы сначала получили сводную таблицу с помощью summarise() (как в главе о предобработке), а затем сразу построили по ней график. Такая связка «агрегируем, затем рисуем» — один из самых частых рабочих приёмов.

7.6 Статистические преобразования внутри графика

Мы можем не готовить сводную таблицу заранее: ggplot2 умеет агрегировать данные прямо в процессе построения графика. За это отвечают функции stat_summary() (общая) и geom_smooth() (сглаживание).

7.6.1 stat_summary()

Функция stat_summary() применяет к значениям y внутри каждой группы функцию и рисует результат заданным геомом. Если функция возвращает одно число (среднее, медиана), её передают в аргумент fun. Если несколько (например, среднее и границы интервала), — в аргумент fun.data.

share |>
  filter(correct) |>
  ggplot(aes(trialtype, time1)) +
  stat_summary(fun.data = mean_cl_boot, geom = "errorbar", width = 0.2) +
  stat_summary(fun = mean, geom = "point", size = 3) +
  labs(x = "Тип пробы", y = "Время первого клика, с")

Такой график называют графиком интервальных оценок (error bar plot, pointrange). В отличие от столбчатой диаграммы, он показывает не только оценку параметра, но и степень её неопределённости. Что именно означает доверительный интервал и как он считается, мы разберём в главе про интервальные оценки.

Заметка

Для работы mean_cl_boot() и mean_cl_normal() нужен пакет Hmisc. Если R просит его установить, выполните install.packages("Hmisc").

7.6.2 Группировка и позиционирование

Когда у нас больше одной группирующей переменной, элементы графика начинают перекрываться. Параметр position управляет их расположением. Для сдвига элементов друг относительно друга используется position_dodge():

pd <- position_dodge(width = 0.5)

share |>
  filter(correct) |>
  ggplot(aes(factor(setsize), time1, color = trialtype)) +
  stat_summary(fun.data = mean_cl_boot, geom = "errorbar", width = 0.3, position = pd) +
  stat_summary(fun = mean, geom = "point", size = 2.5, position = pd) +
  labs(x = "Число стимулов", y = "Время первого клика, с", color = "Тип пробы")

Для диаграмм рассеяния с большим числом пересекающихся точек полезен position_jitter() (или геом geom_jitter()), который добавляет к положению точек небольшой случайный шум:

share |>
  filter(id %in% 1:3) |>
  ggplot(aes(factor(id), time1)) +
  geom_jitter(width = 0.2, alpha = 0.4) +
  labs(x = "Испытуемый", y = "Время первого клика, с")

7.6.3 Сглаживание

Геом geom_smooth() строит линию, описывающую общую тенденцию в данных. Аргумент method = "lm" строит прямую линию (линейную модель, о которых мы будем говорить в главе про линейную регрессию), а method = "loess" — гибкую кривую, повторяющую форму данных:

share |>
  filter(id == 1) |>
  ggplot(aes(numtrial, time1)) +
  geom_point(alpha = 0.3) +
  geom_smooth(method = "lm", colour = "red", se = FALSE) +
  geom_smooth(method = "loess", colour = "blue", se = FALSE) +
  labs(x = "Номер пробы", y = "Время первого клика, с")

7.7 Фасеты

Когда на один график нужно уложить много групп, его можно разбить на панели с помощью фасетов. Функция facet_wrap() раскладывает панели в сетку по значениям одной переменной, а facet_grid() — по значениям двух: одной по строкам, другой по столбцам.

share |>
  ggplot(aes(time1)) +
  geom_histogram(bins = 30, fill = "lightblue", colour = "white") +
  facet_grid(setsize ~ trialtype, labeller = label_both) +
  coord_cartesian(xlim = c(0, 6)) +
  labs(x = "Время первого клика, с", y = "Число проб")

Функция coord_cartesian() ограничила видимую область графика, не удаляя из данных редкие очень медленные пробы. Фасеты особенно хороши для сравнения: у всех панелей по умолчанию одинаковые оси, и разницу между ними видно сразу.

7.8 Оформление графика

7.8.1 Подписи

Функция labs() задаёт заголовок, подпись под графиком и названия осей и легенд. По умолчанию ggplot2 использует названия переменных из таблицы, а они редко подходят для финального графика:

share |>
  filter(correct) |>
  summarise(mean_time = mean(time1), .by = c(trialtype, setsize)) |>
  ggplot(aes(setsize, mean_time, color = trialtype)) +
  geom_line() +
  geom_point() +
  scale_x_continuous(breaks = c(8, 12, 16)) +
  labs(title = "Зрительный поиск замедляется с ростом числа стимулов",
       subtitle = "Только пробы с правильным ответом",
       x = "Число стимулов",
       y = "Среднее время первого клика, с",
       color = "Тип пробы",
       caption = "Данные: эксперимент sharexp")

7.8.2 Шкалы

Функции scale_*() управляют тем, как значения превращаются в элементы графика. Название функции строится по схеме scale_<эстетика>_<тип>: например, scale_x_continuous() для непрерывной оси x, scale_color_manual() для цвета, заданного вручную.

share |>
  filter(correct) |>
  summarise(mean_time = mean(time1), .by = c(trialtype, setsize)) |>
  ggplot(aes(setsize, mean_time, color = trialtype)) +
  geom_line(linewidth = 1) +
  geom_point(size = 2) +
  scale_x_continuous(breaks = c(8, 12, 16)) +
  scale_y_continuous(limits = c(0, NA)) +
  scale_color_manual(values = c(both = "black", dots = "tomato", tray = "steelblue")) +
  labs(x = "Число стимулов", y = "Среднее время первого клика, с", color = "Тип пробы")

Здесь limits = c(0, NA) означает «начинать ось с нуля, верхнюю границу подобрать автоматически».

7.8.3 Темы

Тема (theme) отвечает за всё, что не связано с данными напрямую: фон, сетку, шрифты, положение легенды. Готовые темы — theme_gray() (по умолчанию), theme_bw(), theme_minimal(), theme_classic() и другие. Выбрать тему для всех последующих графиков в сессии можно через theme_set() — именно так мы делаем в начале каждой главы. Отдельные детали подправляют функцией theme():

share |>
  ggplot(aes(trialtype, time1, fill = trialtype)) +
  geom_boxplot(show.legend = FALSE) +
  theme_minimal() +
  theme(axis.title = element_text(face = "bold"),
        panel.grid.minor = element_blank())

7.9 Несколько графиков вместе и экспорт

Объединить несколько графиков в один можно с помощью пакета patchwork: графики, сохранённые в переменные, складываются оператором + (рядом), / (друг под другом) и |.

library(patchwork)

p1 <- share |> ggplot(aes(time1)) + geom_histogram(bins = 40) + labs(x = "Время, с")
p2 <- share |> ggplot(aes(trialtype, time1)) + geom_boxplot() + labs(x = "Тип пробы", y = "Время, с")

p1 + p2

Готовый график сохраняется в файл функцией ggsave(). Она по умолчанию сохраняет последний построенный график, но надёжнее указать его явно:

ggsave("img/my-plot.png", plot = p1, width = 16, height = 9, units = "cm", dpi = 300)

Формат файла определяется по расширению: .png и .jpg — растровые, .pdf и .svg — векторные. Для статей и презентаций обычно удобнее векторные форматы, которые не теряют качества при масштабировании.

7.10 Хорошие и плохие практики

Несколько простых правил помогают сделать график понятным:

  • Подписывайте оси понятно, с единицами измерения. Читатель не должен угадывать, что значит time1.
  • Начинайте столбчатые диаграммы с нуля. Длина столбика должна быть пропорциональна величине.
  • Используйте одинаковые шкалы на графиках, которые вы хотите сравнивать.
  • Не злоупотребляйте цветом. Если различия между группами уже видны по положению, цвет может быть лишним. Для различения групп выбирайте контрастные цвета и проверяйте, как график выглядит для людей с нарушениями цветового зрения.
  • Избегайте круговых и трёхмерных диаграмм. Человеку трудно сравнивать углы и объёмы; столбики сравнивать гораздо проще.
  • Показывайте данные, а не только их сводки. Если наблюдений немного, на график лучше добавить сами точки.
  • Выстраивайте историю. Хороший график отвечает на конкретный вопрос, и заголовок или подпись помогают ему это сделать.

Примеры того, как делать не надо, можно найти на сайте viz.wtf.

7.11 Итоги

  • Описательные статистики не заменяют график (квартет Анскомба, Datasaurus).
  • Любой график в ggplot2 собирается из слоёв: данные, эстетики, геомы, статистические преобразования, шкалы, фасеты, темы.
  • Выбор геома определяется типом переменных: распределение — гистограмма, плотность, ящик, скрипка; частоты — столбики; связь — точки и линии.
  • stat_summary() и geom_smooth() позволяют агрегировать данные прямо в графике.
  • Оформление (подписи, шкалы, темы) — не украшение, а часть коммуникации.
